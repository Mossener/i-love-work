# 班上有书

**表面研读论文，实际追到下一章。**

在本地浏览器中将 EPUB 排成期刊论文：深色 PDF 风格工具栏，默认使用白色 A4 纸张与黑色衬线正文，支持连续滚动和双页并排。保留原书正文与插图，浏览器标签页默认显示中性 PDF 文件名。

## 启动

需要 Node.js 20 或更新版本。Windows 双击 `start.bat`，会安装缺失依赖并打开浏览器；也可在项目目录运行：

```sh
npm install
npm run dev
```

打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。保持终端运行，按 `Ctrl+C` 关闭服务。

```sh
npm run build     # TypeScript 检查并生成 dist/
npm run preview   # 本地预览生产版本
npm test          # 解析、存储、文档生成、搜索与分页测试
```

## 使用

- 按 `Ctrl+O`、将 EPUB 拖入页面，或在右上角 `»` 菜单选择「打开 EPUB 文件…」。macOS 的组合键使用 `⌘`。
- 文档按 A4 页面连续排列。顶部按钮翻页，输入页码后按回车跳转；侧栏「大纲」可跳到章节，「文件」可切换本地书籍。
- 用 `−` / `+` 或缩放下拉框调整比例，也可选择「适合页面」「适合页宽」。双页按钮切换并排显示；窄屏自动显示一页。
- 底部「阅读设置」或 `»` 菜单可调整书籍字号、行距、宋体／黑体／楷体，以及纸白、暖纸、夜间配色。设置会保留；字号、行距或字体变化后会重新分页，并恢复正在阅读的文字位置。
- 阅读位置按页内文字保存，刷新或切换书籍后可继续阅读。底部显示当前章节与按分页计算的阅读百分比，可拖动进度条跳页、切换上一章／下一章，或用返回／前进按钮重访章节、查找结果和书签等跳转位置。
- 使用 `←` / `→`、`PageUp` / `PageDown` 翻页，空格下一页、`Shift+空格` 上一页，`Home` / `End` 跳到开头／结尾；`Ctrl+D` 添加当前位置书签，`Alt+←` / `Alt+→` 返回／前进。这些阅读快捷键在输入框、可编辑区域或对话框中暂停，避免打字时误翻页。
- 底部「书签」保存当前位置；选中正文后点击「划线并批注」，或在侧栏「批注」点击「划线选文」。可添加笔记、选择黄／绿／蓝／粉划线颜色，点击记录返回原文；支持按引用、笔记或章节查找及按书签／划线筛选。每本书最多保存 1000 条，单次选文最多 12000 字。
- 在「批注」面板点击「导出笔记」保存 Markdown，或「备份 JSON」保存可恢复的书签与批注。「导入备份」仅接受当前同一本 EPUB 的 JSON 备份，合并新记录并保留本地已有记录。
- 侧栏「文件」可按书名或作者筛选，按最近阅读、书名或最近添加排序，并显示各书已读百分比。点击书籍恢复其阅读位置。
- `Ctrl+F` 或 `Ctrl+K` 打开全文查找。正文高亮匹配项，`Enter` / `Shift+Enter` 跳到下一项／上一项。
- 正文中的本地章节与注释链接可定位到目标段落；正文引用到的附属 HTML 章节（包括 `linear="no"` 的尾注文件）会在主阅读顺序之后保留。阅读注释后可用底部返回按钮或 `Alt+←` 回到引用处。
- 点击正文插图或 SVG 图示打开大图预览，保留图注。按 `Esc` 关闭预览、查找或弹窗。
- 「文档属性」可修改标签页文件名、论文标题、期刊页眉、作者、单位与年份。正文保留原文；默认论文身份信息为演示内容。
- 点击工具栏文件夹按钮「选择遮挡文档」，选择本地 **PDF 或 Word（.docx）**。PDF 显示原始版式；Word 保留文字、标题、表格和内嵌图片，重新排成 A4 页面。可随时「恢复内置论文」。旧版 `.doc` 需先另存为 `.docx`。
- 按 `Q` 或选择「切换备用文档」，显示所选遮挡文档；再按一次回到书籍的原阅读位置。书籍和遮挡文档分别记住本次阅读位置，输入框内输入 q 不会切换。
- 默认开启「鼠标移出自动覆盖」：鼠标离开页面显示区域时切到所选遮挡文档，未选择时使用内置论文。移回后保持覆盖，按 `Q` 返回原阅读位置；可在 `»` 菜单关闭，设置会保留。导入、弹窗编辑或拖拽文件期间暂停触发，触屏点按不会触发。
- 点击工具栏图片按钮「隐藏图片 / 显示图片」，可去除或恢复 **EPUB 和所选 Word（.docx）正文中的原始图片**，同时控制附加图示。切换后按**正在阅读的文字**恢复位置，即使重新分页改变页码，也会留在同一段原文；图片占满屏幕时定位最近正文。书籍和 Word 分别保留文字位置，按 Q 往返也会恢复；PDF 原始版式不支持此开关。
- 点击打印或下载图标，可通过浏览器打印窗口导出**整份当前书籍或 Word 文档**。自选 PDF 的下载按钮保存原 PDF，打印按钮打开原 PDF 供浏览器打印；PDF 遮挡模式暂不支持页内文字查找。

书籍文件、章节位置及所选遮挡文档存于 IndexedDB；当前书籍、页码、页内文字锚点、阅读进度、阅读设置、书签批注、图片开关、自动覆盖开关、缩放和文档属性等存于浏览器本地存储。刷新后恢复书籍及遮挡文档选择。存储按浏览器、域名和端口隔离，清除站点数据会清空记录，请保留原文件并导出批注备份。

侧栏提供 [EPUB 测试文件](public/samples/paperleaf-sample.epub)，可检验正文、图注、相对图片路径与章节链接。运行 `node scripts/create-sample.mjs` 可重新生成该文件。

## 图示与隐私

原书插图随正文分页并保留图注。`»` 菜单的「附加统计图与结构图」可控制额外图示：篇幅分布来自实际中文字符／英文单词统计，结构图来自原始章节顺序，均附说明，不编造实验数据。参考论文中的三幅图均标注为概念示意。

书籍和遮挡文档在浏览器本地解析，不上传到服务器，不需要 AI API key。PDF 的解析器、字库及字符映射随程序提供；导入时过滤活动内容和外部图片，文档脚本不会执行。

## 范围

- 支持常见的无 DRM EPUB 2 / EPUB 3。单文件最大 **80 MiB**，解压后最大 **250 MiB**。
- 遮挡文档支持未加密 PDF 和 `.docx`，单文件最大 **80 MiB**；Word 解压后最大 **250 MiB**。Word 的复杂版式、页眉页脚及手动分页不保证与原文件一致。
- 不解密 DRM，不支持 ZIP64、分卷 ZIP、固定版式还原、交互脚本和音视频；复杂原书 CSS 统一为论文排版。
- 大型图片书可能占用较多内存。修改文档属性或附加图示会重新分页，页码可能变化。

src/lib/cover-storage.ts     单独保存所选遮挡文档
src/components/CoverPdfPages.tsx 原始 PDF 页面按需渲染
src/lib/reading.ts           章节标题处理、全文匹配与高亮
src/lib/epub.ts              EPUB 解包、清理、资源与链接解析
src/lib/storage.ts           IndexedDB 书库与章节进度
